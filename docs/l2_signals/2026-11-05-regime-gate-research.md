## 二、搜索过程（三轮，全部 T 日收盘可观测）

1. **月度市场方向变量全灭**（最好 15/29 考题月）：上证 >MA60/120/200、20 日动量、
   宽度 >50%、池热度。原因：ON 段不是"市场涨"——2025-01 宽度仅 0.27、
   2026-07 指数跌破 MA200 却 72 笔 @ 87.5%；OFF 框也不全是跌（2025-07~09 宽度 0.7+）。
2. **日粒度单变量有强条件信号但段考不过**：指数当日 >+1% → 82.8% / <-1% → 40.0%
   （单调）；池温倒 U（0.8-1.2×20 日均最优 68.5%，过热 <49%）；并发 N>10 → 68.6%；
   **信号在指数 MA20 之下才灵**（60.2% vs 之上 45.7%——"买回调不追涨"）。
3. **长期位置变量破局**：2024-06 与 2026-07 日粒度同像（指数弱、N 大），区别在
   **牛市回调 vs 熊市中继**——MA200 60 日斜率、距 52 周高点回撤深度把两者分开。
   斜率 >2% 时 70.3% vs 斜率负时 47.0%。

## 三、最终 gate（整数标准值，非网格搜索）

```
gate = (N ≥ 5)                       # 当日信号并发数（聚簇，八-B 处方的 regime 化）
      AND (MA200_60日斜率 > 0          # 上证长期趋势上行（牛市）
           OR 距52周高点回撤 > -10%)    # 或浅回调（牛市回调而非熊市中继）
      AND (上证当日收益 > -1%)          # 非崩盘日
```

经济含义：**"有承接的市场里，大单集体出手的聚簇日"** —— 八-F 判词
（有承接=吸筹指纹，单边熊=接飞刀）的可观测化。三个变量分别对应
聚簇（大单共识）、长期位置（承接的存在）、当日状态（不是接飞刀的日子）。
