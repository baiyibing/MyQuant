# 信号命名：缩量阴线吸筹 `QUIET_DIP_ACCUM`

> **定稿日期:** 2026-11-04 · **数据:** 2026 全市场（core + A 层 + free_float_shares）

## 信号描述

**昨日安静小阳 → 今日阴线回调守住均线 → 大单在回调中吸筹 → 次日反弹。**

## 四条件定义

| # | 条件 | 判定 |
|---|---|---|
| C1 阴线 | T日 开盘≤昨收×1.02 且 最高≤昨收×1.04 且 **收<昨收** 且 **收<开** 且 收>MA5 | 缩量回调阴线，但站上5日线 |
| C2 吸筹 | 大单净量/自由流通股本 > 2% | `freeFloatCapital` 点时查询，订单聚合>10万口径 |
| C3 无暴涨 | T-1 涨幅 ≤ 5% | 排除前日拉爆后出货 |
| C4 缩量 | T-1 阳线（收>开）且震幅 < 5% | 昨日安静小幅上涨 |

### 意外发现：C1+C4 双条件（不需要大单数据）——原表有误，已复核

| 组合 | 原交接 | **可执行口径重跑（2026 至 10-29）** |
|---|---|---|
| C1+C2+C3+C4 | 18 / 61.1% | **18 / 61.1%**（对拍黄金 CSV Exact） |
| C1+C3+C4 | 38,073 / 50.6% | **39,839 / 49.9%**（接近） |
| **C1+C4** | **805 / 67.8%** | **40,884 / 50.2%**（**对不上**；全市场近硬币） |
| 基线 | 39,155 / 46.4% | — |

原「C1+C4 = 805 / 67.8%」用定义卡口径在全市场**无法复现**（次数差约 50×，胜率回到 ~50%）。
`QUIET_DIP_TECH` 按可执行 C1+C4 看待：**不是高胜率信号**。复现脚本
`l2_signals/reproduce_quiet_dip_tech.py`。

**2025 样本外（价域至 09-25）**：C1+C4 **52,655** 次，T+1 **51.3%**（H1 53.1% / H2 48.3%），
与 2026 同属边缘水平，不能当可交易边。
