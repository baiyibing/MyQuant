## 结论先行

1. **算法没有写错。** 同一组 `close/high/low/vol/turnover` 喂进去，本仓内核、backtrader SSOT（`qlib_cost.cyq`）、Rust `turnover-resist` 三端对到浮点误差。和 Rust 锚点对不齐，是换手分母、窗口切法和数据源，不是公式反了。
2. **和券商 `winratio`：排序差别不大，0.10 门槛差别不小。** 2026 重叠 909,663 行，Spearman 0.942、MAE 0.075；整天门槛分歧 9.3%，门槛附近 `[0.05, 0.15]` 分歧 37%。本仓更「松」，多放约 1/4 的深洗日。
3. **和 QMT：同一类量，本仓略激进。** 清洗后 31,684 配对，Spearman 0.921、MAE 0.066；`<10%` 召回 0.950、精确 0.789。Quantile 代理同窗召回只有 0.420，精确版的核心缺陷已补上。
4. **回测过滤继续用本仓 CYQ 外部 parquet。** 券商 `winratio` 若启用是独立 bin 字段，不是这条加载器的替换件。QMT 只有约 9 个交易日且有脏值，只适合抽检。Rust 适合审计，不适合当全市场日频馈源。

## 2. 本仓算法 vs SSOT vs Rust：有没有算错？

### 2.1 公式（三端同构）

都是同一套递推：

1. 价格网格：`min(low) + i × 0.01`，`n = ceil(span/step)+1`
2. 当日成交量按三角分布摊到 `[low, high]`，再归一化使当天质量和 = `vol`
3. `cumpdf_0 = cur_0 × turn_0`；之后 `cumpdf *= (1-turn); += cur×turn`
4. `winner = 网格价 ≤ 收盘的筹码 / 总筹码`（SSOT `ChipFactor.get_cyqk_c` / Rust `calc_cyqk`）

本仓 `_triang_into` / `_stock_winner_ratio_impl` 是这份公式的增量写法。Rust `algorithm.rs` 注释写明复刻 Python SSOT。

### 2.2 同输入数值对拍（2026-09-14 当晚）

三角 PDF（含一字板、`c=0`、`c=1`）：最大点差 `1e-11`，质量和都等于当日成交量。

合成 80 日窗：本仓 = SSOT = Rust = **0.68030633**（差 `1e-16`）。

真票、**同一 1000 日数组、流通股本换手**、末日 2026-09-08：

|---|---|---|---|---|---|
| SH688366 昊海 | 0.066245 | 0.066245 | 0.066245 | `3e-17` | `2e-10` |
| SZ002007 华兰 | 0.240245 | 0.240245 | 0.240245 | `3e-17` | `1e-10` |

### 2.3 和 Rust 锚点对不齐，是口径不是公式

Rust 截面 `cyqk_T`（2026-09-08，流通股本）：昊海 **0.0690** / 华兰 **0.2608**。

| 口径 | 昊海 SH688366 | 华兰 SZ002007 |
|---|---|---|
| 已落盘 parquet（默认自由流通） | 0.1293 | 0.3482 |
| `--shares circ` 构建器冒烟（扩展窗） | 0.0661 | 0.2401 |
| 同数组滚动 1000 日（上表） | 0.066245 | 0.240245 |
| Rust 锚点 | 0.0690 | 0.2608 |

自由流通相对 Rust 差 0.06～0.09，是分母预期差。`--shares circ` 贴上 SSOT 后，剩余几厘来自 **F 湖前复权量 vs bins `$amount/$adjclose`**、**静态 `FloatVolume` vs 逐日 `$basiccurhold`**，不是内核。

### 2.4 有意的工程分叉（不是 bug）

| | 本仓 | SSOT `calc_dist_chips` / Rust `compute_cyqk_series` |
|---|---|---|
| 窗口 | 测试窗前取 `--window 1000`，然后**增量走到结束**（9 月 8 日实际约 1166 日） | 每个 T **重切** `[T-N+1, T]` 并重建网格 |
| 换手默认 | `$netcsfree` 自由流通 | Rust `cyqk_T` = 流通股本 |
| 网格 >25 万点 | 放宽步长，茅台等仍出数 | SSOT 不截；Rust 截面路径会丢 |
| 换手 | clip 到 0.999 | 不 clip |
| 停牌 / NaN | 跳过，分布冻结 | 整窗作废 |
| close 落在 `[low,high]` 外 | 夹进去 | 三角 PDF 变 NaN |
| 一字板定位 | `int` 截断（与 SSOT 同） | Rust 用 `round`；这次对拍未打出差异 |

增量窗 vs 滚动 1000，高换手票差可忽略（昊海/华兰 `|incr-roll|≈1e-4`）。低换手银行会动：浦发 1200 日增量 **0.302** vs 滚动 1000 **0.287**（1.5 个百分点）。过 0.10 门槛一般碰不上；若要审计级贴 Rust 逐日窗口，需要每个 T 重切 1000 日（会慢很多）。

校准脚本：`my_scripts/calibrate_winner_ratio_cyq.py`。代理对照：`calibrate_winner_ratio_proxy.py` / 长窗报告 §7.3。
