## 2. 因果：为什么 50/5+ST 是 +23.2、20/3+ST 是 −3.8

诊断用今早关过滤 50/5 的 `daily_picks` × ST PIT。数字来自主机侧临时对照（未另落 json），量级以分析包为准。

| 观察 | 数 |
|---|---|
| 预测秩 1–20 的 ST 占比 | **21%**（新买里 **29%**） |
| 预测秩 21–50 的 ST 占比 | 8% |
| 关过滤 50/5：ST 持仓合计盈亏 | **−211 万** |
| 关过滤 50/5：非 ST 合计盈亏 | **+547 万** |
| 关过滤曾进前 20 且被买过的名字 | 343；其中 109 只过不了 20/3+ST 闸（这 109 只在 50/5 全关账上 −321 万）；234 只留下 +198 万 |
| 20/3+ST 整本账 | **−1078 万**；新买秩中位 4；持仓 P50/P90 = 6 / 17 日；日均新买 2.81；前 20 每天约 **14** 席 `missed` |
| 50/5+ST 整本账 | **+993 万**；新买秩中位 7；持仓 P50/P90 = 8 / 26 日 |

ST 堆在最尖的头部，不是均匀分布。

- **50/5 开 ST+年龄**：去掉毒头，21–50 合格票补上 → 组合变干净，超额从 +11.8 到 +23.2。换手升高（18→32×）是 walk-down / 资格变窄，不是 n_drop 被改了。
- **20/3 开同一闸**：吃饭的那一层被挖空，没有 21–50 当垫，只能在残缺头部里换 → 换手 48×，左尾更狠，从 +25.0 翻到 −3.8。

P0-4 与此不矛盾：头 1–10 **整体**次日超额最好，但这一层里叠着「真 alpha」和「模型爱打的 ST」。好头和毒头在同一秩段。宽名单 + ST 闸 = 丢掉毒头、留下后排；窄名单 + ST 闸 = 只剩被挖空的头。

**推论**：宽度和过滤是**一个组合单元**，不能先选本窗冠军宽度再叠冠军过滤。20/3 全关与 50/5+ST 数字接近，机制相反，强窗上不必同号。

**刀 2 — P1-2 持仓路径 / 换手结构**  
依据：P0-3 榜内实持中位 10；P0-4 头部最优大量 `not_held`；50/5+ST 换手已 32×；弱窗 10/3 换手 105×、现实档吃 16pp。  
拆：强制出局 / 排序轮换 / 漏买 / 失资格仍拿着。  
若失资格仍持仓 >20%，禁止先跑 n_drop 细表（SYNTHESIS-r2-live P1-2）。

**刀 3 — 训练侧去 ST（结构，先设计后动）**

更稳的跨窗抬法：训练宇宙剔除 ST / 上市未满 60 日，或把 ST、年龄做成特征降权。  
**先做刀 1 的强窗表，再决定要不要动训练**，避免用今日窗标定排除规则。

**刀 4 — 独立第三 OOS 窗**  
2024、无早停污染、purged 出分。用来解 `WINDOW_DEPENDENT`。不要再扫 2025，不要再在 2026-01～09 上找更优 topk。
