## 2. 唯一第一刀（严格按 SYNTHESIS 执行序）

### **P0-1 · topk50 系多窗预锁包（文档零代码）**

写死并落任务书页眉：

1. **三门**：等权超额 sign + 排序稳健（相对基线同序）+ 现实档 sign  
2. **失败标签二阶**：窗口依赖 vs 成本结构不可救  
3. **2025 = 弱证据窗**（早停已消费 valid）；与 2026-04~08 **强窗分权**；过渡双窗须显式写「仅一强窗」  
4. 页眉钉死 **N1 / N2 / N3** 待复核与跨表禁令  

### 为什么不是改 topk / 拧 n_drop / 开过滤默认

| 诱惑动作 | 否决 / 纪律 |
|----------|-------------|
| 单窗改线上 50/5 | **N3**；M3-B OOS 重演风险 |
| 单窗拧 n_drop 救现实档 | **N7**；买入闸拓扑未测前禁止以现实档转正为靶 |
| 开过滤默认 / 默认可拼过滤增益 | **N3** + **N1/N2**；过滤开旧锚仍带 CYQ 疑点 |
| 先跑 P1-5 宽度细扫 | 前置门是 **P0-3**；且验收不以单窗现实档转正为唯一成功 |
| 下调 realistic | **N4** |

P0-2/P0-3/P0-4 都重要，但册内序是 **先钉预锁文档**，再短法医、再同批诊断——避免「数字好看就开扫」把失败标签事后补上。

## 6. 给用户的可执行 checklist

1. **落地 P0-1 预锁包（零代码）**  
   - **动作**：任务书/页眉写死三门、失败标签二阶、2025 弱窗免责、N1/N2/N3 禁令。  
   - **输入**：`SYNTHESIS-r2-live.md` + 本裁决。  
   - **成功判据**：评审人能指出「怎样算 survive / 怎样打窗口依赖 vs 成本不可救」而无需口头补充。  
   - **失败标签**：`DOC_GATE_INCOMPLETE`（三门或弱窗免责缺一条）。

2. **同步今日两轮产物到可分析盘**  
   - **动作**：打包 `exports/analysis/{907edbfb…,8a061ea4…}/`、两份 manifest、两份 `pred.pkl`（及日志）。  
   - **输入**：Win `newtest_4090` 上述路径。  
   - **成功判据**：linux 侧能打开 summary/pred；并注明「未核 raw」已解除或仍缺项清单。  
   - **失败标签**：`ARTIFACT_NOT_SYNCED`。

3. **跑 P0-2（旧两 recorder，关过滤日名单 Jaccard）**  
   - **动作**：`4410e4a3` vs `95e18c5a` 日 Jaccard / 对称差；写是否≥95%。  
   - **输入**：旧 recorder 日名单或可重建名单的 pred+参数。  
   - **成功判据**：中位 Jaccard≥95% → 注记后允许有限拼表；否则书面改对照口径为「跨 PR 不可减」。  
   - **失败标签**：`CROSS_RECORDER_UNVERIFIED`（维持 N2）。

4. **同 pred 固定 50/5 导出 P0-3 + P0-4（优先用可信单 pred，勿混今日两 train）**  
   - **动作**：有效秩深回填表 + 头部分段毒尾；过滤关列先填（开列等有配对）。  
   - **输入**：单一 recorder 的 pred + 每日候选/持仓秩 + 次日收益。  
   - **成功判据**：表含 `rank_max` P50/P90、回填%、分段超额/负尾；能回答「有效宽度是否≪名义 50」。  
   - **失败标签**：`RANK_DEPTH_UNKNOWN` 或 `TOXIC_TAIL_UNSEGMENTED`。

5. **P0-3 门检 → 决定 P1-5 是否降级**  
   - **动作**：若 `rank_max` P90>80 或回填>10% → 标记 P1-5 降级，禁止以单窗现实档转正验收宽度细扫。  
   - **输入**：步骤 4 的 P0-3 表。  
   - **成功判据**：门结果写入任务书（通过 / 降级）后方可设计 P1-5。  
   - **失败标签**：`P1-5_BLOCKED_BY_P0-3`。

6. **成本分列补报（今日窗，过滤关，不改参）**  
   - **动作**：对锁定 pred 报 zero / qlib_default / realistic；缺口>20% 打 `execution-structure`。  
   - **输入**：同一 pred + 冻结的 realistic 假设版本号。  
   - **成功判据**：三档同表；无「用零成本/默认档冒充可上线」表述。  
   - **失败标签**：`REALISTIC_UNREPORTED` 或 `COST_GAP_EXECUTION`（禁止 N7 式拧 n_drop）。

7. **仅当 1–6 闸过：设计 P0-1 宿主双窗跑（仍不改线上默认）**  
   - **动作**：按预锁包跑 2025（弱）+ 2026-04~08（强）；写 survive / 失败标签。  
   - **输入**：P0-1 文档 + 同策略参数冻结集。  
   - **成功判据**：强窗门通过且标签可归因；**默认变更仍挂起至 N3 重提条件**。  
   - **失败标签**：`WINDOW_DEPENDENT` 或 `COST_STRUCTURE_UNSAVEABLE`（后者出 Qlib 执行栈，不进信号层硬拧）。
