#### 为什么这两件事同时成立并不矛盾，但也不构成「S4 已经赢了」

S1/S2 与 S4 判的不是同一个对象，也不是同一个严格度，这一点并版没有拆开：

| | S1 / S2（判 50/5+ST） | S4（判 10/3+ST） |
|---|---|---|
| 比较对象 | 同段 50/5 全关 | 全窗 10/3 全关 |
| 时间分辨率 | **两个不相交段各判一次** | **只判全窗一个点** |
| 打死机制 | 补段 Δ_ST = **−3.9pp** | — |
| 结论 | 不过 → `ST_GATE_SUBPERIOD_ONLY` | 过 |

`50/5+ST` 不是死于「全窗不够高」（它全窗 +23.2%，比 `10/3+ST` 还高），是死于**段检 Δ 反号**。而 `10/3+ST` 从来没有被同一把尺子量过：现有账只有「`10/3+ST` 两段 +21.4% / +22.8%」，**同段的 `10/3 全关` 官方切片至今缺**（round2 handoff §3 自己也这么写；补段约 −13% 是我上一轮的反推，未官方核）。所以 S4 的「通过」在严格度上不能和 S1/S2 的「不过」并列，也就不能直接读成「闸对线上宽度有通用性」。

先把口径对称化，再花重训——这是本刀的全部理由。顺带说，按现有数字反推，这一检**很可能是过**（全关补段若 ≈ −13%，则 Δ_ST 补段 ≈ +35.8pp、强段 ≈ +7.4pp，两段都 ≥ +3pp）。**正因为很可能过，才更要官方核**：把一个「反推出来的通过」写进第三窗预锁，等于用估算数换算力。

### Q2 · `10/3+ST +20.7%`（换手 88×）只记研究增量，成本要不要单独开刀？

**答：不单独开刀。「同一套 `COST_TIERS` 再跑一趟成本」信息量为零；把成本换成两个闭式量（增量分解 + DistanceToPositive），并进 Q1 的 D2 与第三窗预锁的门。**

**理由一：同假设下成本没有新信息。** 上面四本账的每单位换手成本一致到小数点后一位（9.9 / 14.9bp），拖累比稳定在 1.50 —— 成本是换手的线性函数，再跑一趟只是把已知数重算一遍。

**理由二：增量不是成本假设造出来的（闭式分解，我现场算的）。**

| 量 | 值 | 读法 |
|---|---|---|
| Δ_ST（zero，毛） | **+23.96pp** | 闸买到的毛 alpha |
| realistic 下多付的成本 | **+10.12pp** | 换手 43.0× → 88.5× 的代价 |
| Δ_ST（realistic，净） | **+14.59pp** | 成本吃掉毛增量的 **42%**，增量仍活 |

→ **不打** `COST_STRUCTURE_UNSAVEABLE`：增量不是「只在零成本档存在」的那种。

**理由三：DistanceToPositive（P1-3 的闭式版，无需重跑）。** 年化换手 **131.2×**；

- 把 `10/3+ST` 的 realistic **超额**打到 0，需要每单位换手成本从 14.95bp 涨到 **≈ 26.0bp**（往返 30bp → **≈ 52bp**），**1.74× 成本倍数**；
- 打到**绝对净年化**为 0，需要 ≈ **23.8bp**（1.59×）。
  这两个数直接当第三窗的门写死，而不是再开一刀。

**理由四：`88.5×` 本身不是异常，审它会撞 N7。** topk=10 / n_drop=3 每日最多换 3 席 → 双边换手上限 ≈ 0.6/日 ≈ **102×/170 日**。`10/3+ST` 用掉 **87%**，`10/3 全关` 只用 **42%**。也就是说，**闸没有「额外」制造交易，它是把 walk-down 惯性锁住的脏仓（P1-2：失资格仍持仓 20.7%，其中 ST 1369/7060）解锁，让名单跑到 n_drop 本来就允许的节奏**。因此在信号层「审 88× 的成本」在数学上等价于拧 n_drop → 撞 N7 + 20.7% 硬闸。唯一合法的成本追问是**执行层**（ADV 占比 / 冲击 / 131×/年是否真能成交），那按 N5 出 Qlib、另立项，本周只登记不跑。

**理由五（新发现，必须写进门）：成本门差 0.4pp 就要触发。** `cost-tiers` 页的规则是「realistic 相对 zero 的缺口折合换手成本 > 20pp 年化才打 `COST_GAP_EXECUTION`」。`10/3+ST` 的 realistic 年化拖累 = **19.61pp**，缺口（zero → realistic，绝对净）= **18.5pp** —— **紧贴门槛、尚未触发**。50/5 那页的 3.6pp 缺口结论**不能外推到这本账**。

### Q3 · 训练侧去 ST 是否仍与 2024 第三窗合并、本周只设计？

**答：仍合并、本周只设计（我不改口，本周不跑训练）；但合并的理由要改写，并且要把并版「S4 过 → 训练紧迫性下降」这句撤回一半。**

**结构事实（这是我与并版的核心分歧）**：2024 在模型 B 的训练区间内，模型 B 对 2024 出分是 in-sample，**任何 2024 独立 OOS 窗都必须先训一个 purged / 关早停 / 固定轮数的新模型**。所以「押后训练」和「优先第三窗」在物理上不是二选一——**第三窗就是一次重训**。

由此：

- 合并仍然对，但理由从「省算力」改成：**臂 A（原宇宙）是第三窗的必要条件，臂 B（训练期剔 ST + 上市未满 60 日）是同一次训练的边际一列**，不引入新自由度（宇宙定义直接复用既有 CLI 闸的训练期版本）。
- 「紧迫性下降」只对**「训练侧去 ST 作为抬 10/3 的收益杠杆」**成立（S4 过 → 推断期闸已经在线上宽度给出增量）；对**「训练作为第三窗前置」**不成立，甚至上升——因为唯一还活着的研究对象（`10/3+ST`）现在只差一个独立窗，而那个窗只能由重训提供。
- **同 pred 对照（N2）不被毁**：第三窗的 2024 pred 出自新 recorder，**永不**与 `8a061ea4` 的数字相加 / 相减，跨窗只比**符号与排序**；臂 A / 臂 B 之间可比，因为同一次训练、同切分、同轮数、同 seed，只改宇宙。

#### 第三窗预锁（本周只出这张纸，不跑）

切分：2024 全年 OOS；purged 间隔 ≥ 预测 horizon + 5 个交易日；**关早停、固定轮数**（臂 A / B 完全相同）、seed 固定、特征 / handler / 成本三档 / `limit_threshold=0.095` 全部冻结；**不开** `--buy-state-filter`；宽度只报 10/3（线上）与 50/5（历史对照），**不扫宽度网格**。

| 门 | 判据 | 失败标签 |
|---|---|---|
| **T1（符号 / 段检）** | 2024 窗 `10/3+ST` qlib 超额 > 0，且 ≥ 同窗 `10/3 全关` + 3pp；两个不相交子段（H1 / H2）**同号**且各自 Δ_ST ≥ +3pp | `ST_GATE_WINDOW_DEPENDENT`（跨窗不传递）/ `ST_GATE_SUBPERIOD_ONLY_2024`（段内反号） |
| **T2（现实档 / 换手）** | 2024 realistic 超额 > 0 且 Δ_ST(realistic) ≥ 0；年化换手 ≤ 170×；realistic 拖累 < 20pp；breakeven 每单位成本 ≥ 2 × 假设 | `ST_GATE_COST_FRAGILE` / `COST_GAP_EXECUTION` / `COST_BUFFER_THIN` |
| **T3（训练臂）** | 臂 B 在 2024 的 `10/3 全关` 超额 ≥ 臂 A 同格 + 3pp，且臂 B 名单头部不被削（头部命中率不低于臂 A、可填席数不下降） | `TRAIN_UNIVERSE_NO_TRANSFER`（无增量）/ `TRAIN_UNIVERSE_HEAD_DAMAGE`（头部受损） |
