## 卡1 · [d] 否决「默认重开 DropLimitUpLearn」——先做 label-aware 对照体检

### 标题
否决默认重开涨停 learn 剔除；先锁定「涨停样本对 RankIC 的贡献」再谈第三窗重训

### 本仓锚点
路线图 `docs/plan-three-repo-roadmap-2026-09-12.md` §0.2 M3-A：`DropLimitUpLearn` 真跑 IC **0.0183（持平）** / RankIC **0.0048（≈基线 1/3.4）**；代码已合 #9。HOST §2.C 已否线勿重复发明「再开一次就能抬信号」。

### 提案
**纪律级 + 信号级（体检，非默认开）**：在**不改线上默认、不重训**前提下，用既有 pred / train manifest 做离线切片——按「当日是否触及涨停（learn 侧标签）」分组报 IC/RankIC/分位命中；对照「保留涨停样本 vs 剔除」两套体检表。仅当分组显示涨停样本是 **RankIC 的净拖累且 topk 头部分位不受损** 时，才登记「第三窗重训开关对照」；否则保持默认关。

### 收益
直接服务 HOST 方向 d：避免把已崩过的 RankIC 杠杆当下一刀。具体抬的是 **模型体检表** 的两格——(1) 全样本 RankIC vs 去涨停子样本 RankIC 的 Δ；(2) pred 头部分位（P90/P95）在涨停日与非涨停日的命中差——用于决定是否值得烧第三窗训练预算，而不是抬 PortAna NAV。

### 成本与风险
改动面：只读分析脚本/笔记本级，**本轮零代码合入亦可**。若后续开第三窗重训才触发「第三窗」纪律。风险：切片定义与 PIT 涨停不一致会误判；与四开关无关（learn 侧，不碰导出过滤）。

### 冻结检查
不碰线上 topk；不把 NAV 当判优。若有人提案「默认开 DropLimitUpLearn」——**违反**「已有单窗负面证据仍改默认」精神 → 本卡建议否决该默认开法。

### 对抗预填
翻车点：涨停日本身波动大，去涨停后 RankIC「变好」只是样本变干净的幻觉，头部分位名单几乎不动 → 重训白烧。

### 建议裁决
**否决**（针对「默认重开 DropLimitUpLearn」）；**裁剪后采纳**（仅采纳「先做 label-aware RankIC 切片体检」）。

### 重提条件
第三窗（建议 2025 验证 + 2026-04~08 OOS）上，去涨停 learn 使 **RankIC 相对基线回升 ≥50% 且 topk50 过滤开命中/IR 同向不降** 才可讨论默认开关；单窗 IC 持平不算数。

## 卡2 · [d] 盈筹率 CYQ：过滤已兑现 → 特征化进训练登记远期

### 标题
CYQ 已在四开关过滤侧加持 topk50；特征化进 Alpha 集登记远期，本轮不抢第三窗

### 本仓锚点
HOST §2.B PR #39：过滤开后 topk50 默认成本档 **+0.6% → +9.1%（IR +0.27，超额 vs 等权 +6.1pp）**，换手不变 31.1×；#37 精确盈筹率已合。HOST §2.D：CYQ 是已合能力，勿当新发现。过滤路径已吃到 CYQ 红利。

### 提案
**信号级（远期）**：把盈筹率从「导出前资格过滤」升维为 **learn/infer 特征**（分位或桶编码），与四开关正交——过滤仍可开，特征另开实验臂。本轮只登记实验设计：同 handler 增 1–2 列 CYQ 衍生 → 重训 → 报 IC/RankIC + 同 pred 下 topk10/50 名单命中；**禁止**与改 topk 绑在同一臂（不混 M3-B）。

### 收益
目标格：新训后体检表 **RankIC**（相对 ~0.03 基线的 Δ）以及 PR#39 同结构表上 **topk50+过滤开** 的 IR / 超额 vs 等权是否再抬一截。过滤已给 +8.4pp（默认成本），特征化若只重复过滤信息则预期 RankIC Δ≈0——用该零假说当失败准则。

### 成本与风险
改动面：特征工程 + 全量重训（handler_init 级），**触发第三窗纪律**。与四开关关系：互补而非替代；若特征与过滤共线，名单重叠率会极高。风险：CYQ 合并后 topk50 关过滤净值与基线不一致（HOST 疑点）——特征化前须先澄清数据口径，否则污染训练。

### 冻结检查
无（登记远期不改默认）。若有人要求本轮重训抢跑 → 碰「本轮不改代码/不重训」。

### 对抗预填
翻车点：过滤已剔除低盈筹票，特征再喂同一信号 → 模型学不到新排序，RankIC 不动但训练成本全付；或 CYQ 时点/复权口径漂移造成虚假 IC。

### 建议裁决
**登记远期**

### 重提条件
(1) HOST 疑点「CYQ 合并后关过滤明细 vs 基线」查清；(2) 过滤子集消融证明 CYQ 开关有独立贡献；(3) 再开特征臂，且第三窗 RankIC 与 topk50 命中同向为正。

## 卡3 · [d] 中性化：保持默认关；仅当头部行业集中度破阈才重开对照

### 标题
M3-D 已收官噪声级——不重开默认中性化；用「日头部行业集中度」作重提门闩

### 本仓锚点
HOST §2.C：M3-D 两窗命中差噪声级 → 保留开关、**默认关**、不改 topk。`docs/plan-m3d-neutralize-2026-09-13.md`：中性化只作用排序侧；预期 TopN=10 下若日重叠 >80% 则「不改变名单」是有效终点。

### 提案
**纪律级**：明确否决「为抬信号默认打开 industry/size neutralize」。**裁剪动作**：在现有 pred 上只读计算每日 topk10/topk50 的申万一级熵/最大行业占比；预锁阈值——例如 topk10 最大行业占比中位数 **>40%**（或日重叠 raw vs both <80% 的日子占比 >30%）才批准一扇「中性化开 vs 关」对照窗，且与改 topk 分臂。

### 收益
不直接抬 NAV。收益是避免无效第三窗：把预算省给更可能动 RankIC/头部排序的杠杆。若集中度破阈，对照表看的是 **名单命中率 / IR（借 sweep 口径）** 两窗同向，不是 PortAna。

### 成本与风险
本轮：只读集中度统计，零训练。若开门对照：导出侧开关已有，**仍须第三窗**才可改默认。与四开关：中性化在 TopN 前、过滤在资格侧，可组合但须分报告。

### 冻结检查
提案「默认开中性化」→ 碰已收官结论与「单窗不改默认」。本卡本身：**无**（维持默认关）。

### 对抗预填
翻车点：2026 YTD 主题行情下行业集中是 alpha 而非风险 → 中性化削掉真正头部，RankIC 微升但 topk 命中下降（M3-D 噪声的另一种读法）。

### 建议裁决
**否决**（默认开）；**裁剪后采纳**（集中度门闩 + 破阈才对照）

### 重提条件
两窗（含 2025 验证或 2026-04~08 OOS）上 raw vs neutralize 命中/IR 同向改进，且 topk10 日最大行业占比持续高于预锁阈值；否则保持默认关。

## 卡4 · [f] RankIC~0.03 解释框架：弱全局序 + 毒尾在极端头部分位

### 标题
用「分位条件 RankIC / 毒尾质量」解释 topk10 毒 vs topk50 稀释——先体检再谈改模型

### 本仓锚点
HOST §2.A PR #35（recorder 4410e4a3，2026 YTD 166 日）：同 pred 下 topk10/3 零成本 **-33.9%**、超额 **-36.8pp**；topk50/5 **+5.1%**、超额 **+2.1pp**——毒尾被宽度单调稀释。HOST 方向 f 点名 RankIC~0.03。弱截面相关足以让中部名单「平均掉」极端误杀，却不足以保证 Top10 纯净。

### 提案
**复验级 / 纪律级（模型体检）**：在不动模型前提下，对同一 pred 报：
1. 全局 RankIC / IC（确认 ~0.03 量级）；
2. **分位条件**：仅在 pred 真值标签的 top 10% / bottom 10% 子集内的排序相关；
3. **毒尾清单**：每日 topk10 相对 topk50\topk10 的实现收益差、跌停/大负收益占比、行业扎堆；
4. 与 PR#39 过滤开叠表——过滤是削毒尾还是只缩宇宙。

失败准则预锁：若分位条件 RankIC 在头部并不高于全局，则「再堆特征」优先级下降，宽度+过滤才是主杠杆（交给 a/e 席）。

### 收益
抬的是 **解释表** 三格：全局 RankIC、头部条件 RankIC、topk10 独有票的日均超额 vs topk50 共有票。用这三格决定下一刀是信号重训还是名单宽度/过滤——避免 RankIC 小数点上的空转。

### 成本与风险
只读 pred + 收益对齐，不重训、不改 topk 默认。不触发第三窗。风险：实现收益含成本/停牌噪声，须分 zero / 默认 / realistic 分开报（HOST 纪律 3）。

### 冻结检查
无（纯体检）。禁止用该表的 NAV 列改线上 topk。

### 对抗预填
翻车点：2026 YTD 单窗「毒尾」是风格/主题暴露，换 2025 窗头部条件 RankIC 与毒尾结构翻号 → 解释框架窗口依赖，与 M3-B OOS 同一教训。

### 建议裁决
**采纳**（作为 R2/R3 前必做的只读体检；不改产品默认）

### 重提条件
不适用（采纳卡）。若体检显示头部条件 RankIC 已显著高于全局且毒尾可归因，再开卡5 的排序质量杠杆。

## 卡5 · [f] 排序质量杠杆：pred 头部分位校准 / 稳健秩，而非再削 topk

### 标题
在 RankIC~0.03 不变假设下，试「头部校准与稳健秩」抬名单兑现；禁止用再缩小 topk「假装」排序变强

### 本仓锚点
HOST §2.A–B：宽度稀释 + 过滤显著加持 topk50；topk10 过滤后仍深负（-24.0%，IR -0.58）。M3-B OOS：三月冠军 topk5 出窗垫底 → **再缩小名单已被否**。M3-D 中性化噪声。故排序质量杠杆应落在 **分数变换 / 校准**，不是 topk 旋钮。

### 提案
**名单级（排序侧，TopN 之前）**，与中性化开关同层、另臂：
1. **分位秩**：日内 pred → rank percentile，减弱绝对分尺度漂移；
2. **头部温度缩放 / isotonic 校准**（仅 valid 拟合，test 冻结）：压缩极端高分的虚高，观察 topk10 独有票毒尾是否下降；
3. 评估固定在 **同 pred 家族、同 topk10/50、过滤开/关四格**，指标：命中率、IR、零成本超额 vs 等权；成本档分列。

**明确不做**：改线上 topk；把校准与中性化、改 n_drop 绑同一臂；用 PortAna 判优。

### 收益
目标格：PR#35/#39 同结构下 **topk10+过滤开** 的 IR（现 -0.58）能否抬向零轴，以及 **topk50+过滤开** 超额 vs 等权（现 +6.1pp）是否不损。若只改善 topk50、topk10 仍毒 → 说明杠杆仍是宽度稀释，校准登记否决。

### 成本与风险
改动面：导出前分数变换（小）；若校准依赖 valid 拟合，须防泄漏并 **第三窗** 才可默认开。与四开关：先过滤再 TopN 或先变换再过滤须在卡内写死一种顺序并两窗复验。风险：校准过拟合 valid，OOS 头部更毒。

### 冻结检查
若同时改 topk → 碰「不混维度」与「单窗不改 topk」。本卡只动分数变换：**不碰** topk 默认。

### 对抗预填
翻车点：全局 RankIC~0.03 意味着头部分位信息本身不足，任何单调变换不改变秩 → 分位秩无操作；温度缩放若非单调则可能打乱本已微弱的序，topk50 稀释红利消失。

### 建议裁决
**裁剪后采纳**：先做卡4 体检；仅当「头部条件 RankIC > 全局」或「topk10 独有毒尾可分离」时，才上分位秩/校准小臂；默认关，第三窗同向才讨论开。

### 重提条件
2025 验证 + 2026-04~08 OOS：校准臂相对 raw 在 topk10 与 topk50（过滤开）IR/命中同向改进；任一窗 topk10 更深负或 topk50 超额转负 → 否决该变换，回到宽度×过滤主线。
