# Codex · R2-live 想法卡：信号再抬与名单兑现

本轮只提案，未改代码、未重训、未跑实验。成绩采用 HOST 锁定口径；以下“采纳”指采纳后续研究方案，不代表上线。

**核心判断：先确认高分段是否真的排反，再决定改信号。** 全局 RankIC 为正，不保证最前面的十只有效；但 topk10/3 与 topk50/5 同时改变了宽度和淘汰数，其收益差也不能全部归因于排序。

## 卡 1｜把“Top10 毒尾”拆成可证伪的排序体检

- **本仓锚点**：PR #35；`my_scripts/sweep_ranking.py`；路线图 §1.1。HOST 表中，10/3 零成本超额为 −36.8pp，50/5 为 +2.1pp；尚不能凭组合结果定位毒性来源。
- **提案（信号级／复验级）**：
  1. 后续利用已有 pred，在每日同一候选池内固定检查排名 **1–10、11–20、21–50** 三段，报告次日命中率、平均超额、负收益尾部损失及有效样本数。
  2. 原始宇宙、冻结资格过滤后的宇宙分别报告；同时列出各段过滤通过率。
  3. 区分“当天新信号”与“策略留仓”。同池原始 Top10 必然包含于 Top50，所谓“Top10 独有票”只能来自过滤、补位或持仓路径差异，须另表解释。
  4. 头部 RankIC 仅作辅助；不以“头部 RankIC 必须高于全局”为门槛，因为截取窄分数区间后，两者不可直接这样比较。
- **收益**：直接补齐名单体检表的“前十名相对第 11–50 名的命中差／超额差／尾部损失差”。据此判断 PR #35 的改善究竟来自更好的后续名次、风险分散，还是持仓差异；不承诺年化增益。
- **成本与风险**：低，后续仅需已有预测及对齐标签。诊断本身不触发改参第三窗；据此更改 topk/n_drop 必须走 M3-B 和第三窗。
- **冻结检查**：无。四开关按 manifest 的实际定义逐项冻结；MA20/斜率状态另行记录，不能自行视为全部开启。保持 `pred_minus_one`，不将诊断收益当成交收益。
- **对抗预填**：前十名可能只是少数交易日被极端损失拖累，而非持续排反。应按交易日汇总并给出按时间分块的不确定性，避免把相关股票当成独立样本。
- **建议裁决**：**采纳**。
- **重提条件**：若跨窗头部劣化不稳定，停止“毒尾可识别”的推断；只有多个不重叠窗口呈现一致结构，才重提排序修复。

## 卡 2｜CYQ 先验证过滤通过者内部的排序价值，再考虑进模型

- **本仓锚点**：PR #37、#39；HOST §2.B。精确 CYQ 和过滤已接线，50/5 开过滤的默认成本结果为 +9.1%；但过滤贡献尚未证明等于新增排序信息，且关过滤基线存在待查疑点。
- **提案（信号级）**：
  1. 先在**四开关全部冻结、已通过资格过滤**的候选中，按 pred 分位分层，再检查 CYQ 固定粗分组与未来命中／超额的关系。
  2. 分组边界仅由训练或开发数据确定，不扫描 OOS 最佳阈值；缺失值单列。
  3. 若相近 pred 下 CYQ 仍有跨窗稳定增量，才登记一个仅新增 CYQ 连续特征的模型对照臂。暂不扩展大量衍生特征，不同步修改过滤阈值。
- **收益**：目标是提高“50/5＋过滤开”名单表的命中率及零成本超额，而非仅提高全局 RankIC。后续成本敏感性表仍须单列 zero / qlib_default / realistic；不能由现有 +9.1% 推断现实档已转正。
- **成本与风险**：分层体检低成本，进入特征训练后成本高。固定 topk/n_drop/持有期，不触发这三项的改参纪律；模型晋升另预锁独立窗口验证，不能单窗替换默认。
- **冻结检查**：无。CYQ 特征与 CYQ 资格开关分开记录，中性化保持关；仅使用信号时点可得数据。先查清 #39 基线疑点，不重开已判不可比的跨仓筹码映射。
- **对抗预填**：CYQ 可能已被价格、动量特征和过滤充分表达；新增特征只是重复计权。分层关系也可能来自残余风格暴露，不能直接称为因果贡献。
- **建议裁决**：**裁剪后采纳**——采纳条件体检，特征重训登记远期。
- **重提条件**：基线差异解释闭环；过滤通过者内部存在跨窗同向增量；数据时点和缺失机制可核验。缺任一项，不开训练臂。

## 卡 3｜涨停 learn 开关按“名单增量”验收，停止只看 RankIC 倍数

- **本仓锚点**：路线图 §0.2；`my_scripts/custom_train_backtest.py`；`my_tests/test_drop_limit_up_learn.py`。仓内记录 M3-A 的 IC 为 0.0183、RankIC 为 0.0048、较当时基线约 3.4 倍；这与主题中的 RankIC≈0.03 未必属于同 recorder、同窗口或同宇宙。
- **提案（纪律级／信号级）**：
  1. 先建立模型证据对照：recorder、训练窗口、label、learn/infer processors、评估宇宙、四开关、导出日期语义。
  2. 若已有严格配对的开／关 pred，才比较固定名单宽度下的新增票、退出票及其次日命中和超额。
  3. 若没有配对产物，结论写“尚缺名单增量证据”；未来仅登记 learn 开关单变量对照，不为补表立即重训。
- **收益**：补齐“M3-A 相对基线的名单命中率 Δ、零成本超额 Δ”两格，防止把体检改善误写成可兑现收益；同时避免把不同记录的 0.0048 与约 0.03 拼成模型退化结论。
- **成本与风险**：证据核对低成本；缺配对预测时必须另付训练成本。固定排名参数，不触发改参第三窗；任何模型默认变更仍需独立窗口支持。
- **冻结检查**：无。只检验 learn 侧差异；infer 宇宙、四开关和 as-of 完全一致。涨停训练剔除与买入资格过滤分别记账，不互相替代。
- **对抗预填**：剔除涨停样本可能减少不可兑现标签的干扰，也可能删掉有预测价值的市场状态。RankIC 上升但前五十名完全不变，属于体检改善、名单增量为零。
- **建议裁决**：**裁剪后采纳**——采纳证据核对，不凭旧指标重开默认或发起训练。
- **重提条件**：严格配对产物显示名单发生变化且方向一致，才申请下一独立窗；只有 RankIC 倍数，没有名单增量，不晋升。

## 卡 4｜否决“单调校准救排名”；真正重排必须引入额外信息

- **本仓锚点**：`my_scripts/export_daily_pool.py` 的排序导出链；旧脑暴 `docs/reviews/2026-09-15-qlib-perf-brainstorm/r1/codex.md` 卡 5。
- **提案（纪律级）**：否决将截面百分位、正温度缩放或其他严格单调变换作为改善 TopK 排名的实验臂。它们保持顺序，同样的候选池与并列处理规则下，名单不会改变。若未来提出真正重排，必须指出额外信息、信息可得时点及为何能纠正错序。
- **收益**：上述单调方法对名单命中率和名单超额的理论增量为 **0**；采纳否决可省下一条没有排名增益的实验线。
- **成本与风险**：否决本身无实施成本、不触发第三窗。非严格单调变换制造并列后可能改变名单，但改变来自并列处理，不是新增预测能力。
- **冻结检查**：无。固定四开关、候选池、TopK 和中性化状态。若增加阈值或改变名单数量，则已变更提案范围，须单独登记。
- **对抗预填**：概率校准可能帮助解释置信度，但当前产品按排名出名单，没有概率决策环节；不能据此声称能抬升名单年化。
- **建议裁决**：**否决**。
- **重提条件**：产品明确引入需要校准概率的决策目标，或拿出非单调、额外信息驱动且跨窗有效的重排方案。不能以“温度再调一档”重提。

## 卡 5｜中性化重开需证明“暴露导致名单损失”，集中度高不够

- **本仓锚点**：路线图 §0.2 的 M3D-D 收官；`docs/plan-m3d-neutralize-2026-09-13.md`；`my_scripts/ranking_neutralize.py`。两窗未通过同向门，长窗名单重叠超过 80%，默认关。
- **提案（复验级）**：仅登记条件重开：卡 1 若发现头部损失稳定集中于某种行业／规模暴露，先检查这一关系能否跨窗复现，再确定一个中性化方法进行固定配置对照。不能仅凭集中度高重新扫 industry/size/both，也不与 CYQ 特征、过滤阈值或 topk 合臂。
- **收益**：目标格是固定宽度、固定过滤状态下的“中性化前后名单命中率 Δ、零成本超额 Δ”；没有证据前预期增益按未知处理，不计入年化提升预算。
- **成本与风险**：已有模块使后续排序成本较低，但重复选择方法会扩大过拟合风险。固定 topk/n_drop/持有期；默认开关晋升仍须独立验证。当前行业映射回贴历史的偏差须保留脚注。
- **冻结检查**：无。尊重 M3-D 默认关结论；四开关冻结；不动 M5 归因、不改成交。
- **对抗预填**：集中暴露可能就是有效信号，中性化可能把收益来源一起抹掉；而去行业均值也不保证最终名单更加分散。
- **建议裁决**：**登记远期**。
- **重提条件**：不重叠窗口中出现一致的“暴露—损失”证据，且足以形成不同于已收官实验的新假设；仅换窗口或强调集中度，不重开。

## 建议排序

| 优先级 | 卡片 | 理由 |
|---|---|---|
| **P0** | 卡 1：头部分段体检 | 先区分排序问题与持仓路径问题 |
| **P0** | 卡 3：模型证据核对 | 避免跨 recorder 指标误判 |
| **P1** | 卡 2：CYQ 条件增量体检 | 确认过滤后是否仍有新增信息 |
| **P2** | 卡 2 训练部分、卡 5 | 证据触发后再投入独立窗 |
| **不做** | 卡 4：单调校准救排名 | 排序不变，没有名单增益 |

**共同窗口门槛**：2026-04～08 是 2026 YTD 的子区间，可用于定位稳定性，不能充当新增独立证据。2025 窗也须先核对训练与调参使用情况；已看过的 OOS 不再是新方案的盲测窗。涉及线上 topk/n_drop/持有期变更，仍执行 HOST 的两窗同号同排序及第三窗佐证纪律。
