## 4. 为何 A 门很大、B 门极小

A 门（冻结、不重算）：MAXRET 在控制对照 score 截面秩后的 partial RankIC，2025 **+0.0441**，2026 **+0.0385**（CI 下沿 +0.0045>0）。B 门全模型 ΔRankIC 是 +5.08e-5 / +4.63e-4。压缩约 **870× / 83×**。

证据，排除/保留假说：

1. **不是「与对照 score 高度共线」。** 日均 Spearman(对照 score, MAXRET) 只有 0.22 / 0.14。该列自身 vs label 的 RankIC 2025 为 +0.053，与对照 RankIC 同量级，且 A 门残差后仍有 +0.044，说明相对 *score* 仍有增量。
2. **更像「被其它 183 列吸收」。** 加进 LGB 后 ΔRankIC 塌到 1e-4 量级；候选对该列的相关只多 0.005。split/gain 显示它被拿去切树，但切完不改变截面秩的有效排序。
3. **「只在非头部有效」只对了一半。** 按对照 score 五分位，特征 vs label RankIC（2025）：Q1（低分）0.071 > Q5（高分）0.038，头部更弱但仍为正。对照 Top100 vs 其余：0.058 vs 0.054，几乎一样。所以不是「身体有、头没有」，而是 **头的 *持仓* 由别的列主导，落在 anti-rank 左尾**，线性残差 IC 进不了 Top10。
4. **A 日度与 B 日度几乎脱钩。** corr(partial RankIC, ΔRankIC)：2025 **−0.088**，2026 **+0.372**。2025 特征增量大的日子，模型并不跟着赢 RankIC。

一句话：A 门量的是「给定 8a 分数后，该列还有没有线性残差信息」——有。B 门量的是「把该列丢进与 8a 同结构的 LGB 后，全模型秩和 Top10 有没有稳定变好」——没有。残差信息没有变成秩差。
