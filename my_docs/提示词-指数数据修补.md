# 提示词：F 湖指数 → qlib bin 数据修补

> 给 AI agent（Codex/Claude）或未来的自己。固化自 2026-09-12 的实修：当晚为修
> PortAna benchmark 抛 `ValueError: The benchmark ['SH000300'] does not exist` 手工走通全流程。

## 任务

给 `~/.qlib/qlib_data/my_data`（纯个股、无任何指数行情）补指数日线，使 Qlib 回测的
benchmark（SH000300 等）可用。数据源是 F 湖：`F:\stock_data\index\period=1d\dividend_type=none\symbol=XXXXXX_XX\data.parquet`。

## 执行方式

**先跑现成脚本，不要手工拼命令**（坑都在脚本里堵好了）：

```bash
cd E:\PycharmProjects\MyQuant
D:/anaconda3/envs/vanna312/python.exe qlib_scripts/patch_index_data.py
# 默认：补 000300_SH + 000001_SH，自动备份 → 裁剪 → dump_fix → all.txt 挪移 → 读回验证
```

参数：`--symbols 000905_SH,...`（换/加指数）、`--no-backup`、`--skip-verify`、`--force`（覆盖率缺口时强行写入）。
ETF 同理可做：`--lake-root F:/stock_data/etf/period=1d/dividend_type=none`。

## 三个坑（为什么必须走脚本）

1. **湖的 `time` 是 UTC 毫秒**，要转 Asia/Shanghai 再取日期。直接按 UTC 取日期，收盘段（15:00 CST = 07:00 UTC）没事，但凌晨段会**错一天**。
2. **bin 按日历位置索引**。必须把数据裁到 qlib 日历（`calendars/day.txt`）范围内再写；且**绝不能从 `cn_data` 直接拷 bin**——它的日历（2005 起 5062 天）和 `my_data`（2020 起 1518 天）不同，拷过去全部错位。
3. **`dump_fix` 会把新标的写进 `instruments/all.txt`**，而训练宇宙 `market="all"` 读的就是它。指数留在 all.txt 会：① 混进训练样本；② 名单导出时 `SH000300` 被剥成 `000300` 当股票买。脚本会把指数行挪到独立的 `instruments/index.txt`（提供 `market="index"` 池；基准查询 `D.features(['SH000300'],...)` 不依赖 all.txt 会员资格，已验证）。

## 验收标准（全部满足才算完成）

- [ ] 裁剪后 `rows == calendar天数`、`缺日 == 0`、`nan_close == 0`（脚本会打印；异常默认中止）
- [ ] qlib 读回：全日历范围行数 > 0、close 无 NaN、首末值与湖一致（2026-09-12 实例：沪深300 4152.24 → 4636.57，上证 3085.20 → 3986.23）
- [ ] `market="all"` 宇宙里**没有**指数（脚本末行打印"指数泄漏: 无"）
- [ ] 重训（`my_scripts/custom_train_backtest.py`）PortAna 段不再抛 benchmark 错误，日志出现 `[alignment]` 对齐自检输出

## 回滚

- 整体：还原备份目录 `my_data_backup_YYYYMMDD_pre_index`（脚本每次运行自动先做）
- 单标的：删 `features/shXXXXXX/` 目录 + 从 `instruments/index.txt` 去掉该行

## 全量刷新（股票数据重建）流程

指数补丁只管指数；股票数据全量重建（新 CSV 批到了 / 湖更新了）走另一条链，
2026-09-13 实跑过一次，完整状态与陷阱清单见 `docs/qlib-data-state-2026-09-13.md`：

```bash
# 1. 旧 bin 存档(字段全、2020 起) + 新 CSV 批(字段全、2022-07 起) 拼成 staging
python qlib_scripts/merge_archive_and_csv.py --out-dir <staging>
# 2. 全量灌入新目录：--max_workers 8（16 会进程池死锁）；禁用 dump_update（停牌即错位）
python qlib_scripts/dump_bin.py dump_all --data-path <staging> \
    --qlib-dir <新目录> --file-suffix .parquet --max_workers 8
# 3. 切换目录后重补指数（本脚本）
python qlib_scripts/patch_index_data.py --no-backup
```

注意：湖的股票日线只有 7 列基础行情（无 zhangting/factor/筹码），**不能单独作训练数据源**；
旧存档里的指数会借「退市股」通道混进 all.txt（陷阱 3 的变体），第 3 步会自动挪走。
