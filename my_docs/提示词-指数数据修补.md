# Qlib 指数数据修补（infra 入口）

指数修补实现已迁到 MyQuant-infra。日常完整刷新统一按[日线刷新手册](提示词-qlib-bin刷新.md)运行 `refresh-daily`，由它调用 patch 并完成门禁和 provider 交换。

单独修补仅用于明确指定的本地 provider。先检查
`python -m myquant_infra.adapters.qlib_data patch-index --help`。
安装同 [README](../README.md#环境搭建)，不得从其他 provider 复制指数 bin。

配置湖容器 `OSKH_SOURCE_PARQUET_ROOT`、目标日线 provider `MQ_QLIB_DAILY_DIR` 和独立工作目录 `MQ_QLIB_INDEX_STAGING` 后：

```powershell
python -m myquant_infra.adapters.qlib_data patch-index --lake-root "$env:OSKH_SOURCE_PARQUET_ROOT/index/period=1d/dividend_type=none" --qlib-dir "$env:MQ_QLIB_DAILY_DIR" --staging-dir "$env:MQ_QLIB_INDEX_STAGING"
```

此命令直接操作指定 provider，不提供整库交换事务；执行前保留可恢复备份并停止其他写入。
输入 `time` 是 UTC 毫秒，按上海日期裁到目标日历。指数写入 `instruments/index.txt` 并从股票 `all.txt` 排除。
默认做 Qlib 读回；仅在明确不做读回时使用 `--skip-verify`。
结束后检查实际日历起止、指数覆盖、抽样 OHLCV 和股票宇宙排除结果，不凭文件存在判断验收通过。

实现及测试在 infra 的 `myquant_infra/adapters/qlib_data/patch_index_data.py` 与 `tests/adapters/qlib_data/`。
