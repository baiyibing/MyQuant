# 提示词：收盘后次日买入名单

> 发给实施 agent（Cursor / Codex）或未来的自己。SSOT：本文件 + `my_scripts/export_next_day_pool.py`。
> 固化自 2026-09-15 收盘后第一次实跑：bin 到 2026-09-15 → 已有 50/5 模型对当日截面出分 → ST+年龄（不开买入状态）→ 2026-09-16 全套 CSV。

把下面整段发给做「今天收盘 → 明天买什么」的人 / agent。**不是回测复盘，不是重训。**

---

## 角色

你在跑**收盘后次日计划名单**。用户刚把今天的交易数据灌进 qlib bin，要的是**明天开盘准备买/留/卖的股票**，不是再训一遍，也不是改线上默认 10/3。

## 钉死的契约

| 项 | 值 | 不要做 |
|---|---|---|
| 模型 | recorder `8a061ea428e04bb3a199a485ade49d0e`（LGB Alpha158CostKDJ，50/5 研究窗） | 不要重训；train/valid 锁在 2026 年前，多一天 test 不构成重训理由 |
| 出分日 | qlib 日历**末日**（今天收盘） | 不要用昨天的分去报明天的买 |
| 买入日 | 出分日的**下一交易日**（`pred_minus_one` / TopkDropout `shift=1`） | 不要把今天的分当成今天就能买（那是未来函数） |
| 闸门 | **ST PIT + 年龄 ≥ 60**；**买入状态关** | 不要自行打开 `--buy-state` / MA 买点 |
| 宽度 | 研究名单 `topk=50` / `n_drop=5` | 不要改线上默认 10/3 |
| 产物 | `exports/live_pool/<买入日YYYYMMDD>/` | 不要覆盖 recorder 的 `pred.pkl` |
| 解释器 | `D:\anaconda3\envs\vanna312\python.exe` | 不要 vanna310 / 系统 Python |

`st_daily.parquet` 若停在更早的日期（例如 2026-09-08），代码用 **≤ 买入日的最近一日** 快照，不会当成空集。缺档才报错。

日历末日往前推时 handler cache **必 miss**（fingerprint 含日历末日）。重算约 10–12 分钟、写出约 10.6 GiB，属预期，**不是重训**。

2. **工作目录**：`D:\PycharmProjects\MyQuant`。
3. **可选**：`python my_scripts/build_tradable_universe.py` 刷新 `all_tradable.txt`（ST PIT + 上市满 60 日）。本脚本出分用 `market=all`，不依赖该文件；刷新只为和训练宇宙对齐。
4. **对照持仓**：默认读 `exports/analysis/8a061ea4_50n5_st_age/positions_daily.csv` 里**出分日**那一行。没有该日则退回文件里最后一天，并在日志里说清楚。没有这个文件则只出目标 Top50，不拆新买/留/卖。

## 产物（同一目录，稳定文件名）

目录：`exports/live_pool/<买入日YYYYMMDD>/`

| 文件 | 用途 |
|---|---|
| `new_buy.csv` | **明天计划新开**（对照收盘持仓后的增量） |
| `hold.csv` | 计划留仓（含 n_drop 惯性、不在次日 Top50 的老仓） |
| `sell.csv` | 计划卖出（榜外持仓里分数最弱的 `n_drop` 只） |
| `daily_picks.csv` | 一张表：`new_buy` / `held` / `held_not_topk` / `plan_sell` |
| `target_topk.csv` | 资格过滤后的次日目标 Top50（不管现在持不持） |
| `pred_<出分日>.csv` | 当日全市场分 + `eligible` / `is_st`（ASCII 名，不写中文文件名） |
| `pred_ranked_all.csv` | 同上，方便和人工表对齐 |
| `positions_eod.csv` | 用来对照的收盘持仓切片 |
| `blocked_head80.csv` | 裸分前 80 里被 ST/年龄挡掉的 |
| `suite.meta.json` | 出分日 / 买入日 / 行数 / 闸门 / `retrain=false` |

先把 `new_buy.csv` 交给用户。人工核对时再打开 `daily_picks.csv` 和 `blocked_head80.csv`。

这套表是**计划调仓近似**（Top50 vs 收盘持仓 + n_drop），不是再跑一遍 PortAna，也不是 `export_daily_pool.py` 的裸六位实盘池契约。线上 10/3 池子仍走原来的 export。

## 盘后清单（按这个顺序写）

1. **日期对不对**：`suite.meta.json` 里 `pred_date` = 今天收盘，`buy_date` = 下一交易日，`retrain` = false。
2. **资格**：`eligible_rows`、`blocked_in_raw_top80`；ST parquet 是否在用旧 as-of（看日志 / `st_note`）。
3. **调仓**：`new_buy` / `plan_sell` / `hold_including_inertia`。卖出不是「不在 Top50 的全部清掉」，只丢最弱 `n_drop` 只。
4. **不要写**：不要因为这一天名单好看就改线上 topk；不要把研究 50/5 写成已经上线。

## 不要做

- 不要重训，不要改 train/valid 切分
- 不要写回 `mlruns/.../pred.pkl`（那是原实验 2026-01-05.. 窗）
- 不要为了「再导出一次」去 `--replay` 整段回测（那是盘后复盘，见 `提示词-盘后人工分析.md`）
- 不要打开买入状态过滤（MA20/MA60 / 赢筹），本路径已关
- 不要改 `export_daily_pool.py` 的裸六位 / LF / 无 BOM 契约
- 不要把 handler cache miss 当成事故；日历末日变了就会 miss
