# R2 prediction as-of decision

Date: 2026-09-12

`LOCKED_ASOF=pred_minus_one` — the prediction index is the after-close signal/feature day, while Qlib's trade day consumes the preceding prediction bar.

## Evidence

- A recursive search under `/workspace/MyQuant` found none of `my_scripts/预测结果.csv`, `my_scripts/预测结果和真实标签.csv`, any `pred.pkl`, or any filename containing `预测结果`; therefore no local datetime index, columns, or gaps could be measured directly.
- The documented sample is `datetime,instrument,score`, with 16 trading dates from 2026-03-02 through 2026-03-23 and about 5,479 rows per day. It skips the weekend gaps 2026-03-07/08, 03-14/15, and 03-21/22. The test segment starts on Sunday 2026-03-01, so its first dataset/prediction date is Monday 2026-03-02; `topk` is 10.
- `SignalRecord.generate()` saves `model.predict(dataset)` as `pred.pkl`; the training script loads that artifact and writes `预测结果.csv`, whose documented MultiIndex is `(datetime, instrument)` with column `score`. The older 2025 example dates in comments are not dates from this run.
- Vendor `Alpha158.get_label_config()` returns `["Ref($close, -2)/Ref($close, -1) - 1"], ["LABEL0"]`. `Alpha158CostKDJ` does not override it. `CostKDJSignalHandler.get_label_config()` returns the same Alpha158 result; its comment claiming `Ref($close, -2) / $close - 1` is wrong. Thus label[D] is `close[D+2]/close[D+1]-1`; features at D use data through D's close, and pred[D] is a signal after D's close rather than a same-day buy list.
- Vendor `TopkDropoutStrategy` calls `get_step_time(trade_step, shift=1)` before `signal.get_signal(...)`; `TradeCalendarManager.get_step_time` defines positive shift as earlier bars. Trade day T therefore consumes pred[prev(T)].
- The pool contract defines the filename as buy day T. Accordingly, `file[T] = TopN(pred[prev(T)])`; `prev` and `next` must come only from dates present in the prediction file, never `D.calendar` or a weekday/holiday guess.

## Implication for Slice C

Default `--asof` to `pred_minus_one`, while still implementing both `pred_minus_one` and `identity`. Under the lock, each pred date D writes `next(D).csv`: the first file is `20260303.csv`, the final pred date 2026-03-23 writes no file, and 16 pred dates produce 15 files. `--start` and `--end` follow output filenames.

Residual risk: the ignored prediction artifacts are absent on this VM, so a real file could still reveal pre-shifted buy/fill-day dates; the inherited label, dataset-index persistence, Qlib shift, and documented sample together support H0 unless such a file disproves it. No training-script changes are made, and R3 is out of scope.
