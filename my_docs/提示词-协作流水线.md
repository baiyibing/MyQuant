# MyQuant 研究实施与宿主验证提示

通用开发流程见 [grok-bot-ops](https://github.com/baiyibing/grok-bot-ops/blob/master/docs/handoff/development-workflow.md)，
交付证据见 [generic DoD](https://github.com/baiyibing/grok-bot-ops/blob/master/docs/handoff/generic-dod.md)。
本仓的研究验收口径见[研究约定](../docs/pipeline-collab-2026-09-13.md)，本文只保留研究操作提示。

## 实验实施

- 阅读实验任务书的范围、预锁判读、数据窗口与参数，按任务约定选择 Qlib 训练、回测和分析组件。
- 使用本仓 `task_scaffold.py` 生成的模板记录采纳条件、合法终点、禁止说法与预期管理；通用执行核归 ops。
- 数据采集、provider 产制与公共读侧调用 infra；特征、中性化、策略筛选、PortAna/Exchange 回测及信号导出留在本仓。
- 完整研究回归入口：`python -m pytest my_tests tests my_scripts/test_zhangting_filter.py -q`。

## 宿主实验验证

- handler 初始化验证按相同配置合批；一次性脚本同样使用 main guard，Windows 多进程按需 `freeze_support()`。
- 记录数据与模型身份、窗口、参数、启动时 Git 溯源和真实产物路径，核对 as-of、文件字节和 manifest。
- 盘后已有结果可直接展开为分析包；需要比较新成本、策略参数或收益时可重新运行 Qlib 回测/replay，分别保存结果。
- 信号质量、组合收益、执行假设和实际交易验收分别说明；研究结论按任务书的预锁规则判读并回写实验记录。
- 日频/分钟数据准备遵循各自[日线](提示词-qlib-bin刷新.md)与[分钟](提示词-qlib-1min-bin刷新.md)手册。
