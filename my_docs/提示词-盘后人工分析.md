# 提示词：qlib 实验盘后人工分析

> 配套代码：`my_scripts/analysis_export.py`。训练收尾默认落包；补导出用 `export_positions_trades.py`（**默认不重回测**）。

把下面整段发给做盘后阅读的人 / agent，并附上本次 `exports/analysis/<recorder_id>/` 路径。

---

## 角色

你在读**已经跑完**的 qlib 实验，做盘后人工复盘，不是再训一遍，也不是改默认参数。

先读目录里的 `summary.json`，再按需打开 CSV。不要手算持仓差分，不要重跑 `handler_init`。

## 产物（同一目录，稳定文件名）

| 文件 | 用途 |
|---|---|
| `summary.json` | 天数 / 买卖笔数 / 盈亏合计 / 与净值变动对账 |
| `timing.json` | 实验墙钟 rollup + `D.features` 计数（优化用，不是判优） |
| `nav_daily.csv` | 组合日净值、成本、换手、基准（PortAna 原件） |
| `daily_picks.csv` | **每日荐股**：交易日 T 用 T-1 的 pred TopK，对照是否实持 |
| `positions_daily.csv` | 收盘后持仓快照（含持有天数、权重、现金） |
| `trades_daily.csv` | 买卖流水（持仓差分，整笔调仓） |
| `ledger_by_stock.csv` | **按股票流水账**：买/持/卖 + 均价 + 当笔已实现 + 当日浮动 + 累计已实现 |
| `pnl_by_stock.csv` | 按股汇总（与流水账同源） |

`daily_picks.action`：

- `new_buy`：荐股且当日新开
- `held`：荐股且已在仓
- `missed`：荐了但没买上（涨停拒单 / 资格过滤 / 现金 / n_drop 惯性）
- `held_not_topk`：在仓但不在当日 TopK（n_drop / hold_thresh 留仓）

as-of 已锁：`pred_minus_one`（交易日 T ← pred[T-1]），与 TopkDropout shift=1、池 CSV 契约一致，不重开。

## 盘后清单（按这个顺序写，不要跳到「策略该怎么改」）

1. **净值**：`nav_daily` 首末日 account、最大回撤日、成本累计。`summary.pnl_total` 与 `nav_delta` 的 diff 只作对账，diff 大先查卖出价（清仓日用 $close，缺行退前日价）。
2. **荐股 vs 实持**：按日数 `missed` / `held_not_topk` / `new_buy`。missed 多 = 执行层吃掉信号；held_not_topk 多 = 调仓惯性，不是模型当天最想买的。
3. **个股流水**：对 `pnl_by_stock` 盈亏两端各翻 5 只，用 `ledger_by_stock` 看开平日期、持有天数、均价、是否一天游。
4. **结构**：持仓天数分布、单日权重是否顶满 topk、有没有反复进出同一只。
5. **结论纪律**：单窗、单 recorder **不算数**。能写的是观察（「这 30 天 missed 里 8 成是涨停拒单」），不能写「应把 topk 改成 20」除非任务书预锁了多窗门槛。

## 不要做

- 不要为了「再导出一次」去 `--replay` 或重训
- 不要改 `export_daily_pool` 的裸六位 / LF / 无 BOM 契约（那是实盘名单，不是盘后表）
- 不要把 PortAna 净值当成模型晋升依据（晋升看 IC/IR/名单命中率）
- 不要在分析会话里改线上默认 topk / n_drop / 闸门

## 导出怎么来的（宿主备忘，不必贴进分析会话）

- **训练当时**：`custom_train_backtest.py` 在 PortAna 之后写 `exports/analysis/<recorder_id>/`。跳过：`--no-export-analysis`
- **事后补导出（同一实验）**：`python export_positions_trades.py --recorder-id <id>`  
  只读 `positions_normal_1day.pkl` + `pred.pkl`，秒级
- **换成本 / topk / 闸门才第二遍**：加 `--replay --test START:END`（仍不重训，只重放 PortAna）
